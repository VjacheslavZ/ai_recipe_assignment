# Brand kit — GymBeam Croatia (@gymbeamhr)

Human-supplied inputs for the recipe. The pipeline never invents products or
logos: every product shown in a post is a real photo from this folder.

| Path | What to put here |
| --- | --- |
| `logo.png` | Official logo at the brand root. PNG with transparent background, ideally ≥ 1000 px wide. |
| `products/` | Real product photos to promote. Ideally transparent PNG or a clean white background, ≥ 1500 px on the long side. Name files by product, e.g. `true-whey-chocolate.png`. Record the product page URL for each in the brief. |
| `instagram/` | 6–10 screenshots of recent @gymbeamhr posts/stories (feed grid + a few individual posts). Used by the vision model to analyse tone, colours, layout and how products and people are shown. Name them `01.png`, `02.png`, ... |
| `fonts/` | Brand font files (`.ttf`/`.otf`/`.woff2`) **only if licensed** for this use. If empty, the compositor falls back to a similar open-licence font. |

Sources and access dates for each asset should be noted in the brief.
