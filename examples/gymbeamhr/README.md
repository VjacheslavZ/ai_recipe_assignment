# Example inputs — GymBeam Croatia (@gymbeamhr)

The files of the demo run. **Load the GymBeam example** on the Start a run page puts the
starting prompt ([PROMPT.md](../../PROMPT.md)) in the text field and these files into the
run's inputs, where they show as previews and can be removed or replaced. Nothing here is
read by a run directly: every run gets its own copy in `runs/<runId>/inputs/` (ADR-033).

| Path | What it is |
| --- | --- |
| `logo.png` | GymBeam wordmark, black on white. A one-colour logo is cut out and shown white or black, whichever reads on the slide. |
| `products/gymbeam-protein-fusion.png` | GymBeam Protein Fusion, chocolate (transparent PNG). Page: https://gymbeam.hr/protein-fusion-gymbeam.html |
| `products/gymbeam-32-protein-wafer.png` | GymBeam 32% Protein Wafer (transparent PNG). Page: https://gymbeam.hr/32-protein-wafer-gymbeam.html |
| `instagram/` | 10 screenshots of @gymbeamhr posts (October 2026), for the style analysis. Instagram blocks automated access, so these are taken by hand. |

For another brand, upload the same kinds of files on the Start a run page: a logo, a photo
per product (transparent PNG or white background; the file name helps match it to the
product), and 6–10 screenshots of the brand's Instagram. **Find the logo and product photos**
can download the logo and packshots from the brand's website instead.
